NIGHTWARD - Ilhans Bar (Tilesets Aussen + Innen)
=================================================
Raster 32x32 px, Point-Filter, PPU 32, keine Kompression, keine Skalierung (Import wie Tileset_Haus).
Palette: Style-Bibel (Art/Palette.gpl, 39 Farben), Check: 0 Fremdfarben, kein Alpha ausser 0/255. Outline #1a1526.
Akzentfarbe der Bar: gedaempftes Rot (#7a2e3a / #c4636b) = Ilhans Geschirrtuch (Schilder, Laeden, Markise, Barhocker, Sitznische).
Erzeugt mit _Quelle_Generator/bar_aussen.py, bar_innen.py, bar_meta.py (Python + PIL; bar_lib.py = Palette/Schrift).
Aenderungen: Skripte anpassen, "python bar_aussen.py && python bar_innen.py && python bar_meta.py" im _Quelle_Generator-Ordner.
Vorschau: Bar_Aussen_Vorschau.png, Bar_Innen_Vorschau.png (nur Ansicht, nicht fuer Unity noetig).

Preise auf den Tafeln (Waehrung = Wachtgroschen, WG): Bier 1, Met 1, Wein 2, Korn 2, Whisky 3, Rum 3, Bourbon 4.
Texte auf Schildern sind in die Sprites gezeichnet (5x7- bzw. 3x5-Pixelschrift, kein Font noetig).

LICHTQUELLEN fuer Light 2D: beleuchtete Fenster (Aussen fenster_lit, gaube_lit; Innen fenster_lit, fenster_vorhang),
Wand-/Haengelaternen, Laternenpfosten, Pendeltuer (Innenraum-Glow), Kamin-Ersatz: Kanonenofen, Kronleuchter, Wandleuchte,
Theke Kerze/Zapfhahn-Lichtinsel, Klavier-Kerzen. Kein Strom (1910): Oel, Kerze, Ofen.
