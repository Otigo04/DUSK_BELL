# Claude-Memory (Sync-Kopie)

Kopie der Claude-Code-Memory von Haupt-PC. Auf neuem Gerät einmal in den Memory-Ordner des Projekts kopieren:

    ~/.claude/projects/<projektpfad-slug>/memory/

Slug = Projektpfad mit `:`, `\`, `/`, Leerzeichen -> `-` (z. B. `F:\!!!_GAMES\NIGHTWARD\Nightward` -> `F------GAMES-NIGHTWARD-Nightward`).
Am einfachsten: In dem Projekt `claude` einmal starten, dann den Ordner unter `~/.claude/projects/` suchen und die `*.md` (inkl. `MEMORY.md`) hineinkopieren.
Nach Änderungen an der Memory hier erneut synchronisieren.
